# Contributing to PromptShield AI

Thank you for helping make everyday AI use safer.

## Good first contributions

- Add a detection rule together with positive and negative tests.
- Improve keyboard navigation, contrast, labels, or screen-reader output.
- Improve English or Urdu copy.
- Add a new translation without changing the privacy model.
- Clarify documentation or examples.

## Development workflow

1. Fork the repository and create a focused branch.
2. Make the smallest change that solves the issue.
3. Add or update tests for detection behavior.
4. Run `npm test`.
5. Open a pull request explaining the problem and the change.

Never commit real personal data, credentials, private URLs, or production secrets. Use clearly fictional test values.
