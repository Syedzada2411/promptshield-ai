# Security Policy

## Supported version

The latest version on the `main` branch is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not publish real credentials, personal data, or exploit details in a public issue.

Include the affected file, expected behavior, observed behavior, and a minimal fictional reproduction. Reports will be acknowledged as soon as practical.

## Scope

PromptShield is a client-side pattern scanner, not a guarantee that every sensitive value will be detected. Users must review results before sharing them.
